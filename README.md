# AyurdhA Website MVP

A premium Indian traditional-food brand website inspired by the supplied Ayurveda website reference. The redesign uses warm ivory, charcoal and muted gold, large photographic sections, generous whitespace, editorial serif headings and alternating image/text blocks.

## Included
- Responsive homepage
- Hero, brand statement, About, Products, Saritha's story, family legacy, promise, preparation guides and contact
- Client-side enquiry cart
- Dummy checkout/enquiry flow that opens WhatsApp
- No login, payment gateway, inventory backend or real order processing
- Product prices and pack sizes intentionally remain unfinalised

## Run
Open `index.html` in a browser or serve the folder with any static web server.
